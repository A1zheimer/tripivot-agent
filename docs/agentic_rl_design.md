# Agentic RL 设计：从单轮策略后训练到轨迹级优化（第二阶段）

> 定位：本项目的 OPD/GRPO 试点完成了**策略级后训练**并验证了 RL 基础设施
> （奖励管线/组采样/KL 稳定性）。本文档定义其 agentic 化路径——在仓库现有的
> agent 循环上做轨迹级 RL 与轨迹蒸馏。

## 1. 为什么单轮后训练是 agentic RL 的必要前置

- 轨迹级 RL 的探索空间是指数级的（每轮一个决策点），弱策略会让轨迹奖励
  全军覆没、组内方差为零、GRPO 优势估计失效——**先有强单轮策略才有可学习的轨迹信号**
- 本项目已验证的三块地基直接迁移：奖励复合函数（chrF+格式+术语）、组采样机制、
  KL 锚稳定性（试点全程 <0.001，无奖励黑客）

## 2. Agent 轨迹定义（复用现有组件，零新框架）

```
状态 s₀: source + 文档上下文 + 术语表
动作 a₁: 初译（policy 采样）
观测 o₁: TerminologyReflector.audit_document() 的结构化反馈
          （缺失术语清单 / 格式问题 / 一致性告警）
动作 a₂: 条件重译（prompt = 原文 + 反馈 + 首译）
终态: 译文'（可扩展 k 轮，受 audit 收敛/预算约束停止）
```

轨迹 τ = (s₀, a₁, o₁, a₂, …)。仓库的 HierarchicalPlanner（文档→句块）与
audit→定向重试循环即天然的环境步进器。

## 3. Trajectory GRPO（主方法）

- **组采样**：每条 source 采 G=8 条**完整轨迹**（初译+重译都带温度）
- **终态奖励**：R(τ) = 0.5·chrF(final) + 0.2·术语命中率(final) + 0.2·格式完整
  − 0.1·轮数惩罚（鼓励一轮到位，防无脑重试刷分）
- **优势**：组内标准化（同现有实现）；多轮 token 的 logprob 按轨迹拼接计算
- **KL 锚**：对整条轨迹的所有动作 token 做 β·KL(π‖π_ref)，防轨迹漂移
- 关键工程点：两轮动作共享同一 LoRA（条件生成），无需分离策略头

## 4. Trajectory OPD（对偶方法）

- 教师跑同一 agent 循环产生轨迹（教师的重译决策也采样）
- 学生 on-policy 跑轨迹，教师对**学生轨迹的每轮动作**给逐步 logits
- 反向 KL 按轮拼接；试点暴露的长度坍缩问题在轨迹版通过轮数奖励间接矫正

## 5. 评测协议

- 主指标：文档级 chrF/COMET（整篇聚合而非句级平均）+ 术语终态命中率
- Agentic 专属指标：**重试有效率**（第二轮相对第一轮的指标增益）、审计-修复
  一致率（反馈指出的问题是否真被修复）、轮数分布
- 对照组：单轮 GRPO（已完成）/ 2-turn GRPO / 2-turn OPD / agent 循环+无 RL

## 6. 实施分期

| 期 | 内容 | 依赖 |
|---|---|---|
| v0（1 夜） | 2-turn GRPO mini：100 prompts，审计反馈重采，终态奖励 | 全部组件现成 |
| v1（1 周） | 完整 2-turn × en-zh + 术语奖励消融 | v0 验证 |
| v2 | k 轮自适应停止 + 文档级轨迹（HierarchicalPlanner 全链） | v1 |

## 7. 与已完成试点的衔接（答辩口径）

> "第一阶段的单轮后训练回答了'哪种信号塑形策略更有效'（GRPO 综合最优、
> OPD 单句最优），并验证了奖励管线与 RL 稳定性；第二阶段把同一套机制
> 升维到 agent 轨迹——审计反馈成为环境观测，重试成为策略动作，
> 终态质量成为轨迹奖励。"
