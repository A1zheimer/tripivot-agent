# Apple · Mac OS X

၂၀၀၁ ခုနှစ်၊ မတ်လ ၂၄ ရက်တွင် Apple က Mac OS X v10.0 ကို မိတ်ဆက်ခဲ့သည်။ ၎င်း၏ အစောပိုင်းထုတ်ပြန်ချက်များသည် အတော်နှေး၊ မပြည့်စုံသော လုပ်ဆောင်ချက်များနှင့် သီးခြားဖွံ့ဖြိုးသူများမှ software များသာရှိသည်။ အမြင်အများအပြားက ၎င်းသည် အရွယ်ရောက်သော လူသိများမှု ထုတ်ကုန်မဟုတ်သော်လည်း အလားအလာရှိသည့် ဖွံ့ဖြိုးရေး ပရောဂျက်တစ်ခုအဖြစ် မဆုံးရှုံးပါ။ Apple သည် Mac OS X ကို ၁၉၉၆ ခုနှစ်ကတည်းက ပြန်လည်ရေးဆွဲခဲ့သည်။
