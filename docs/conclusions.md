# 实验结论（终版 v2，2026-09-08 复核修订）

> 全部数据实测于 HKUST(GZ) HPC2；评测明细 `artifacts/eval/`，训练日志 `artifacts/logs/`。
> v2 修订：BLEU 分词器修正（zh 用 `zh`、my 用字符级近似、en 用 `13a`；旧值保留为
> `bleu_tok13a`）；补配对 bootstrap 显著性检验；RL 作用范围表述校准。
> chrF++ 为逐句均值（corpus 级值见 `chrfpp_corpus` 字段）。

## 一句话总纲

面向缅甸语/中文/英语翻译，交付了数据管线、SFT 微调、策略级后训练对比与轨迹级 v0、
以及全自动化训练工程：**SFT 在低资源缅向带来大幅提升；试点规模下两种后训练方法与
基线无统计显著差异，但暴露出可解释的行为特征差异；Agent 层面证据为下一步工作**。

## 结论 1：领域数据 + LoRA 微调对低资源方向收益巨大

| 方向 | COMET | BLEU（修正分词） | chrF++ |
|---|---|---|---|
| zh→my | **+42%** (0.445→0.631) | **+76%** (0.244→0.430, char) | **+81%** (0.187→0.339) |
| my→zh | +11% (0.685→0.762) | **+80%** (0.092→0.165, zh) | **+62%** (0.113→0.184) |
| zh→en | −5% | +16% (0.183→0.213) | +6% |
| en→zh | ≈0 | +8% (0.229→0.248) | +7% |

- 原版 Qwen 中译缅 **55% 输出退化文本**，微调后 37%
- zh→en 回退（COMET −5%、退化率 11%→22%）解读为**四方向共享单一 LoRA 的容量竞争**：
  低资源方向大幅获益的同时高资源方向受损；改进为分方向 adapter / 语向重采样（展望第一条）

## 结论 2：试点规模下 OPD/GRPO 与基线无显著差异；行为特征差异稳健

en-zh、252 条 held-out（BLEU 已按 zh 分词修正）：

| 指标 | baseline | OPD-R1 | GRPO-R1 |
|---|---|---|---|
| COMET | 0.7921 | 0.7984 | 0.7927 |
| BLEU(zh) | 0.2478 | 0.2582 | 0.2603 |
| chrF++ | 0.2579 | 0.2581 | 0.2622 |
| 长度比 | 1.320 | **0.737** | 1.223 |
| 退化率 | 3.57% | **0.00%** | 3.17% |

- **配对 bootstrap（1000 次）：所有两两对比 p > 0.46，均不显著**
  （`artifacts/eval/significance.json`）——试点规模不足以分辨方法差异
- **稳健发现是行为特征**：OPD 的长度坍缩（0.737）+ 退化清零，符合反向 KL 的
  mode-seeking 与教师风格迁移预期；GRPO 长度健康、KL 锚全程 <0.001（RL 过程稳定）
- **空结果的机理**：en→zh 恰是 SFT 增益最小的方向（COMET 持平），句级空间近饱和、
  headroom 最小；全量版应优先 zh→my
- 方法学定位：GRPO 为**单步策略梯度（contextual bandit 范畴）**；OPD 为**教师蒸馏
  （非 RL）**；两者的对比是"稠密教师信号 vs 稀疏指标信号"

## 结论 3：轨迹级 v0 已跑通，核心发现是环境校准

2-turn agentic GRPO v0（审计反馈→条件重译→轨迹 PG）一次通过：
800 步、KL 锚 0.0007。**审计触发率仅 0.4%**（3/800）——SFT 策略在简单审计下
很少产生硬伤，轨迹退化为单轮。结论：**审计标准必须严到"重译是真实决策"**，
v1 需引入 chrf 阈值/术语精确匹配等软标准触发。

## 结论 4：自动化流水线是实验可行性的前提

（同 v1）多队列竞速+自动降级在饱和集群拿到全部算力；9 类工程问题全修复；
VPN 断连 8+ 次训练零中断。

## 结论 5：文档级证据——SFT 训练将 Agent 审计一次通过率提升 10 倍

同一篇 19 块的技术文档、同一审计标准（术语缺失/退化/过短）：

| 组 | 模型 | 审计不通过率（需重译） |
|---|---|---|
| A | 原版 Qwen2.5-7B + Agent 机制 | **52.6%**（10/19） |
| B | SFT LoRA + Agent 机制 | **5.3%**（1/19） |

- **A→B 是"训练对 Agent 生态位贡献"的直接证据**：微调后的模型在术语遵循与
  完整性上一次通过审计的比率从 47% 升至 95%
- 度量边界（诚实声明）：术语跨块一致性指标存在度量缺陷（在中文输出中检索
  英文术语的启发式不成立），该指标未采用；B vs C（Agent 机制本身的贡献）
  依赖修复后的一致性度量，列为后续工作

## 诚实边界（更新）

1. OPD/GRPO 为 en-zh 试点（n=252，headroom 最小方向），方法间差异未达显著
2. RL 作用于 Agent 调用的**句级翻译策略**；Agent 自身的规划/修订决策仍为规则驱动——
   agentic RL（episode 级奖励+跨步信用分配）是下一步，其必要性由**译法冲突**这一
   纯文档级失败模式驱动（单看任一 chunk 译文正确，冲突只在跨 chunk 出现，句级奖励
   原理上无法覆盖）
3. 奖励用 chrF 而非 COMET（模型获取约束；两分支同尺）
4. zh→my 参考来自蒸馏，指标上限受参考质量约束；my 的 BLEU 为字符级近似
5. 文档级证据目前限于审计一次通过率（A→B，结论 5）；术语跨块一致性与
   Agent 机制本身的净贡献（B vs C）因度量缺陷列为后续工作
