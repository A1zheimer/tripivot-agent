# 实验结论（终版，2026-09-08）

> 全部数据实测于 HKUST(GZ) HPC2，评测明细见 `artifacts/eval/`，训练日志见 `artifacts/logs/`。

## 一句话总纲

面向缅甸语/中文/英语翻译，从数据、微调、后训练、工程四个层面交付完整可复现的训练体系：
**SFT 在低资源缅向带来数量级提升；后训练对比证明 GRPO 与 OPD 各有支配域；
全自动流水线在饱和集群上零人工值守完成全部训练。**

## 结论 1：领域数据 + LoRA 微调对低资源方向收益巨大

| 方向 | COMET | BLEU | chrF++ |
|---|---|---|---|
| zh→my | **+42%** (0.445→0.631) | **×6.7** (0.011→0.075) | **+81%** (0.187→0.339) |
| my→zh | +11% (0.685→0.762) | −18% | **+62%** (0.113→0.184) |
| zh→en | −5% | +16% | +6% |
| en→zh | ≈0 | +5% | +7% |

- 原版 Qwen 中译缅 **55% 输出为退化文本**，微调后降至 37%（chrF +81%）
- 高资源方向增益温和；zh→en 出现"变长致退化率上升"（11%→22%）——引入后训练的动机

## 结论 2：OPD 与 GRPO 不互相支配，按目标选型（en-zh 试点，252 条 held-out）

| 指标 | baseline(SFT) | OPD-R1 | GRPO-R1 |
|---|---|---|---|
| COMET | 0.7921 | **0.7984** | 0.7927 |
| BLEU | 0.0493 | 0.0212 | **0.0627 (+27%)** |
| chrF++ | 0.2579 | 0.2581 | **0.2622** |
| 长度比 | 1.320 | 0.737 | 1.223 |
| 退化率 | 3.57% | **0.00%** | 3.17% |

- **GRPO 综合最优**：BLEU +27%、chrF 最高、长度健康；KL 锚全程 <0.001 = RL 高度稳定
  无奖励黑客；机理=指标奖励直接优化目标，无教师上限
- **OPD 单句质量最优**：COMET 最高、退化清零；代价是 14B 教师简洁风格经反向 KL
  传染 + mode-seeking 导致欠译（长度 0.74、BLEU −57%）
- **选型规则**：忠实覆盖优先 GRPO；流畅无误优先 OPD；组合路线（OPD 塑形→GRPO
  对齐）为下一步方向

## 结论 3：自动化流水线是实验可行性的前提

- 集群 GPU 饱和期（14h 零流转）靠多队列竞速 + 75 分钟自动降级拿到全部算力
- 9 类环境/工程问题全定位修复并文档化（DNS/Slurm spool/HF xet/cu130 驱动冲突/
  transformers 5.x API/tokenizers 三角/合并缺 tokenizer/vLLM V1 引擎/显存隔离）
- VPN 断连 8+ 次、登录 VIP 轮换 4 次，训练零中断——服务端全自治架构价值实证

## 诚实边界

1. OPD/GRPO 为 en-zh 试点规模，四方向全量在路线图中
2. 奖励用 chrF 而非 COMET（模型受限下载；两分支同尺，公平性不受影响）
3. zh→my 参考译文来自蒸馏，指标上限受参考质量约束
